额度与缺失值

UNKNOWN 表示没有可信观测，不代表额度为零。只有真实 remaining percentage 才绘制进度条与趋势。

预测门槛

当前重置周期至少 6 个样本并完成 walk-forward validation 后才会预测；否则明确显示“历史数据不足，暂不预测”。

统计方法

速率按真实时间差计算；EWMA 抑制短期噪声；Theil–Sen 降低单点异常影响；burst 使用 rolling median + MAD。

本地与隐私

flowfoundry control-center 只监听 127.0.0.1。SQLite 仅保存归一化指标，不保存 credential、transcript 或隐藏推理。

Provider 命令

Codex：codex；Claude Code：claude；Grok Build：grok；Gemini：gemini。

跨模型比较限制

百分比额度、local token usage 与 session tokens 不是同一变量。本页不会生成伪造的综合健康分数。
