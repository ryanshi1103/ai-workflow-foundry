# Launch Story

Status: draft narrative for a future authorized Alpha announcement

## The moment

AI capability is no longer concentrated in one interface. Developers use one
tool for code, another for review, local utilities for validation, and human
judgment for permission and release decisions. Models keep improving, but the
coordination burden still belongs to the person.

That is the problem FlowFoundry is built to explore.

## The insight

The future is not only a smarter individual model. It is a system that can
coordinate suitable intelligence resources around a goal while preserving
constraints, evidence, recovery, and human authority.

FlowFoundry does not try to replace Claude, Codex, DeepSeek, local models, or
developer tools. It treats eligible models and tools as resources behind a
local-first coordination boundary.

## What the Alpha proves

The current Alpha can profile and plan bounded work, route capabilities,
execute deterministic offline workflows, coordinate review, persist approvals,
recover interrupted state, record usage when available, and isolate
write-capable candidates in managed Git worktrees.

The flagship story begins with a familiar developer goal:

> Prepare my GitHub release.

The synthetic fixture makes the plan and routed roles visible, records review
and evidence, and stops the package task for human approval. It does not claim
to have run real project tests, built artifacts, called live models, or
published a release.

## Why local-first

Projects, policies, run state, and evidence belong to the user by default. A
remote provider is an explicit choice, not an invisible premise. Unknown cost
stays unknown. Review does not grant approval. A failure is preserved as a
recoverable product state.

## Where it could go

The designed next step is a Personal AI Command Center: an approval-first phone
interface, not remote desktop. It would show bounded tasks and evidence while
credentials and execution remain on the computer.

The longer-term Personal AI OS direction would add user-owned context with
privacy, provenance, correction, export, expiry, and deletion. Neither the
mobile surface nor personal memory is shipped today.

## Invitation

This Alpha is for developers, students, researchers, and AI builders who want
to test coordination as infrastructure. Try the offline workflow. Inspect the
approval boundary. Report the first confusing step. Improve an example, test,
diagnostic, or tutorial.

Do not chase every new model. Help build a system that coordinates them.
