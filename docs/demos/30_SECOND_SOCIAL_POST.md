# 30-Second Social Post

Status: draft channel asset; publication requires separate authorization

More AI models do not automatically create a better workflow.

FlowFoundry is a local-first AI coordination layer: start with a human goal,
route eligible models and tools, preserve permissions and evidence, recover
from failure, and stop for approval before consequential action.

The current Alpha has a deterministic offline demo. Mobile control and personal
memory are future work.

**Do not chase every new model. Build a system that coordinates them.**
