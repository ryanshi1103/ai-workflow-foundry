# FlowFoundry Alpha Limitations

Status: **canonical limitations for the first external Alpha**
These limitations are part of the product contract, not a temporary disclaimer
to hide during demos.

## Release and support

- FlowFoundry is an Alpha developer preview, not production software.
- The final documentation-integrated candidate, public tag, wheel, sdist,
  hashes, remote CI, independent install, and public demo assets do not yet
  exist.
- Supported-platform claims remain provisional until the final artifact matrix
  passes.
- Maintainer response targets are proposed for a limited cohort and are not a
  service-level agreement.

## Provider execution

- Deterministic fake providers are the default evidence path.
- Offline routing identities do not mean Claude, Codex, DeepSeek, or another
  cloud provider was called.
- Live provider setup, parity, version compatibility, cancellation behavior,
  usage reporting, and cost completeness are experimental.
- FlowFoundry does not provide every assistant, model, framework, copilot, or
  automation-system adapter.

## Planning and intelligence

- Goal profiling and routing are explainable rule-based Alpha behavior, not
  universal understanding or an optimal model selector.
- The system cannot guarantee correctness, quality, security, lowest cost, or
  the best provider.
- Model or fake-provider outputs remain candidates until trusted checks and
  people review them.
- Missing cost or usage data remains unknown; the system does not have a
  complete learned cost/quality optimizer.

## Side effects and human authority

- The official first-user workflow does not modify repository files or run the
  project's real tests.
- It does not merge, push, create a pull request, tag, deploy, publish, make a
  financial transaction, or widen permissions.
- Approval records are scoped workflow evidence; they do not replace repository,
  provider, deployment, or financial authorization.
- Users remain responsible for goals, permissions, review, and consequential
  actions.

## Data, privacy, and security

- Local-first does not mean risk-free. Local run state can contain project or
  provider output and must be handled as user data.
- Real providers may receive context when explicitly enabled; users must inspect
  provider and permission boundaries first.
- The project has security boundaries and tests but no claim of security
  certification or complete vulnerability absence.
- Historical remote containment and independent final-candidate review remain
  open release gates.
- Credentials, private prompts, user paths, and customer data must not be placed
  in issues, fixtures, recordings, or version control.

## Installation and packaging

- Source installation may require network access to obtain the declared build
  backend.
- Offline runtime and offline installation are different claims.
- Historical wheel/sdist evidence from an earlier SHA cannot be used for the
  final candidate.
- Optional providers and bundled components have separate dependencies; the
  root package does not install every component environment.

## User interfaces

- The supported product experience is CLI/terminal oriented.
- The launcher preview is a rendered representation of a tested terminal
  contract, not a screenshot of a graphical client.
- The Mobile AI Command Center, iPhone PWA, and native applications are designed
  but not implemented.
- There is no unrestricted remote terminal or remote desktop product.

## Personal AI roadmap

- Complete personal semantic memory, preference learning, personalized
  intelligence, and a Personal AI OS are future work.
- Operational run state and basic performance history must not be marketed as a
  personal-memory system.
- FlowFoundry does not claim AGI, universal intelligence, autonomous human
  replacement, or authority independent of the user.

## Excluded content

- Feedback Intelligence and the Customer Intelligence demo are excluded from
  this Alpha because approved publication licensing was not available.
- Excluded applications, private sessions, incident archives, and unrelated
  migration history are not part of the public candidate.

## How to use these limitations

README, release notes, installation instructions, demo narration, screenshots,
website copy, and issue templates should link here. If observed behavior exceeds
or contradicts this boundary, stop the release and update executable evidence
and canonical documentation before changing the claim.
