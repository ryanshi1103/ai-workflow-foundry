# FlowFoundry brand assets

- `logo.svg` is the editable vector logo.
- `logo.png` is the README icon.
- `social-preview.png` is the 1280 × 640 repository link preview.

GitHub's social preview is set through the repository website: **Settings →
Social preview → Edit → Upload an image**. Upload `social-preview.png` from
this directory. This is a repository setting; placing the file in the source
tree alone does not activate it.
